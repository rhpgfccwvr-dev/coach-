# Мастер Коммуникаций — PWA

Готовая PWA-версия тренажера.

## Файлы

- `index.html` — приложение
- `manifest.json` — настройки PWA
- `sw.js` — офлайн-кэш
- `icons/` — иконки

## Как загрузить в GitHub

1. Создай новый репозиторий на GitHub.
2. Назови его, например, `master-communication`.
3. Загрузить все файлы из этой папки.
4. Открой Settings → Pages.
5. В разделе Build and deployment выбери:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
6. Нажми Save.
7. GitHub даст ссылку на сайт.

На iPhone открой ссылку в Safari → Поделиться → На экран «Домой».

## Сохранение

Прогресс сохраняется автоматически в `localStorage` на устройстве:
- текущий вопрос;
- текущий счет;
- завершенные тренировки;
- лучший результат;
- общая точность;
- изученные модули;
- изученные правила.
